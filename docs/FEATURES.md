# ✨ MinAI Features

# 📄 AI PDF Chat

Chat naturally with uploaded PDFs using grounded Retrieval-Augmented Generation (RAG).

Example:

```text
What is clustering?
Explain Unit IV.
Difference between SVM and Logistic Regression.
```

MinAI retrieves relevant chunks from uploaded PDFs before generating answers.

This ensures:

✅ grounded educational responses  
✅ reduced hallucinations  
✅ source-based explanations  
✅ contextual understanding  

---

# 💬 Normal AI Chat

MinAI also supports general AI conversations outside uploaded PDFs.

This mode is useful when users want:

✅ general knowledge answers  
✅ brainstorming  
✅ coding help  
✅ explanations outside uploaded documents  
✅ casual AI interaction  

Example:

```text
Explain how neural networks work.
What is quantum computing?
Write a Python sorting algorithm.
```

Unlike PDF Chat mode, Normal AI Chat:
- is NOT restricted to uploaded PDFs
- uses the LLM’s general knowledge
- provides broader AI assistance

# 🚨 Hallucination Prevention

MinAI is designed to answer ONLY from uploaded PDFs during RAG mode.

If information is absent:

```text
"The requested information is not present in the uploaded document."
```

This prevents:

❌ fake answers  
❌ fabricated explanations  
❌ outside-knowledge hallucinations
