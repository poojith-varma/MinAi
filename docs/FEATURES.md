# ✨ MinAI Features

# 📄 AI PDF Chat

Chat naturally with uploaded PDFs.

Example:

```text
What is clustering?
Explain Unit IV.
Difference between SVM and Logistic Regression.
```

---

# 🧠 Multi-PDF Workspace

Upload multiple PDFs simultaneously and chat across all documents.

Example:

```text
Compare deadlocks in DBMS and OS.
```

---

# 🔍 Hybrid Retrieval

MinAI combines:

- Semantic Search
- BM25 Keyword Search

for better retrieval accuracy.

---

# 🧠 AI Flashcards

Automatically generates:
- revision flashcards
- question-answer cards
- memory-based learning cards

---

# 🎯 AI Quiz Generator

Generates:
- MCQs
- answers
- explanations

directly from PDFs.

---

# 📝 AI Summary Generator

Creates:
- concise notes
- revision summaries
- educational explanations

---

# 📤 PDF Export

Export:
- summaries
- flashcards
- quizzes
- notes

as beautifully formatted PDFs.

- source PDF
